# Contributing to VOX

Thank you for your interest in Future-by-Fie. This is an early concept prototype, not a production-ready product.

## Before contributing

- Open an issue describing the problem, proposal, intended behavior, and any privacy or security implications.
- Keep pull requests small; include a reproducible test and update documentation when behavior changes.
- Run `npm run check` locally (Node.js 20+). Do not submit personal information, credentials, or recorded audio.
- Clearly distinguish implemented capabilities from research goals. Never describe a demo as production-grade security or AI.
